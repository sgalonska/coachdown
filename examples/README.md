# Examples

> Full specification: https://github.com/sgalonska/coachdown/blob/main/SPEC.md

All examples are **fictional**. People, organisations and situations are invented. Each example shows a different way Coachdown is used in practice.

| Example | Shows |
| --- | --- |
| [`minimal.coach.md`](minimal.coach.md) | The smallest useful log: no front matter, one session, a few markers |
| [`fictional-engagement.coach.md`](fictional-engagement.coach.md) | A complete log: engagement sections, Progress, reviews, decisions, perspective, cancelled session, `[AI]` summary |
| [`google-docs-style.coach.md`](google-docs-style.coach.md) | A log kept in Google Docs: meeting-notes headings with calendar links, same-level headings, `About this log` instead of YAML, name instead of tag, coachee-written agenda |
| [`pair-coaching.coach.md`](pair-coaching.coach.md) | Two coachees in one engagement: tagged lines, shared statements, perspective of people who left |
| [`team-interviews.coach.md`](team-interviews.coach.md) | Interviews with team members as `type: interview` sessions, with consent rules |
| [`deutsch.coach.md`](deutsch.coach.md) | A German log: German section names, `TT.MM.JJJJ` dates, `(nicht stattgefunden)`, Entwicklung as growth story |
