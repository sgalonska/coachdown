# Coachdown Agent Instructions

## Golden rule: no client data in this repo

- **Never commit a name from a client session**, and never an example taken from one. This covers people, companies, places, quotes, anecdotes and situations from real sessions, in any file: docs, examples, templates, tests, fixtures, commit messages, issues and PRs.
- All examples must be fictional. If an example is inspired by a real session, invent new names and change the details until it cannot be traced back.
- This repo is public. Anything committed or pushed here should be treated as published.
